更适合 OI 宝宝体质的 Linux 入门.

序言

Linux 是一种自由和开放源码的类Unix操作系统. 第一个 Linux 内核由 Linus[1] 在 1991 年 10 月 5 日首次发布.

目前 Linux 的开发受 Linux 基金会支持, 但同时也与另一个享誉世界的计划: GNU 计划有千丝万缕的联系.

内核, 终端与发行版

严格意义上来说 Linux 单指 Linux 内核 (即 Kernel), 多样化的程序依靠 Kernel 与硬件实现交互构成了丰富多彩的系统 (OS). Kernel 为全体程序提供了统一且稳定的接口, 同时还具有最高权限.

发行版是一般来说你可以用最简单的方式在网上搞到的东西. 一个发行版一般来说封装了 Kernel, 部分用于支撑 Kernel 运行的程序和库, 以及一些便于使用的实用程序. 以上有许多程序都基于 Python 等程序编写, 因此不出意料你很容易在 Linux 发行版中找到 Python 的运行环境 (尽管可能有诸多限制, 不过笔者十分建议 OIer 掌握基本的 Python 编程能力). 大部分发行版都有一个大抵能看的图形化界面, 一个 Firefox 浏览器, 一些没什么用的办公套件.

终端是供给用户与 Kernel 交互的程序, 常见的终端包含 bash, zsh 等, 实际上 Windows 中的 cmd 和 Powershell 也是一种终端, 只不过底层原理, 指令等等都有所差异. 终端相比于一般的图形化交互有诸多好处, 我们将会在下文仔细探讨, 本文近乎所有内容都是基于 bash 而来的.

本文或许并不会涉及到内核之类的具体底层原理, 但请读者对 Linux 有基本的认知.

搞一个 Linux 终端最简单, 最轻量化的方法

你可以说用 VMware 装一台 Ubuntu, Debain 或者别的发行版的虚拟机, 但是我要提醒你一点虚拟机或多或少都存在对资源的浪费, 而且我不建议非要搞一个难用的图形化界面. 在我看来在 Windows 上使用 Linux 最简单的方式是利用微软官方工具 wsl 且强烈建议 wsl2. wsl 占用无论是 cpu 资源还是存储资源都远低于普通的虚拟机, 且你不必使用难用的 GNOME 桌面. 有关 wsl 的详细介绍与安装说明都可以在微软官网找到.

发行版选择: 我推荐你使用 Ubuntu, 因为首先这是使用最广泛的发行版, 其次它是考试环境 NOI Linux 的上游版本, 内容大同小异.
